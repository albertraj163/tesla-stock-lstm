Tesla Stock Forecaster

LSTM model for Tesla (TSLA) stock price prediction

Run locally on your machine

http://localhost:5555

Start the server first, then open this link in your browser.

How to run

git clone https://github.com/albertraj163/tesla-stock-lstm.git
cd tesla-stock-lstm
pip install -r requirements.txt
chmod +x run_server.sh
./run_server.sh
